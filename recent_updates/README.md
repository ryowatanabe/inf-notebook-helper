# recent_updates

## 概要

直近のプレイ履歴・更新履歴をOBSに表示するためのHTMLです

## 使い方

1. `recent_updates.html`, `recent_updates.js`, `recent_updates.css` を、リザルト手帳のインストールフォルダの下の `export` フォルダ内にコピーする
2. コピーした `recent_updates.html` をOBSのブラウザで組み込む

## カスタマイズ

`recent_updates.js` の先頭で定義された変数を変更することでカスタマイズ可能です  
詳しくはコード内のコメントを参照してください
